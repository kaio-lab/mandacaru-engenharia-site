Ambas foram copiadas para `public/media/articles`. Os logos disponíveis foram copiados para `public/media/clients`; o wordmark **ICON REALTY** permanece textual para preservar a legibilidade aprovada.

Os ativos copiados são arquivos locais no repositório. A versão publicada por GitHub Pages ou outra hospedagem estática não dependerá das URLs temporárias utilizadas apenas durante a exportação.

## Validação final

A prévia independente confirmou o logo institucional, os cinco logos de clientes disponíveis, o wordmark ICON REALTY e as duas capas editoriais servidos por caminhos locais em `./media`. Os dois links externos de leitura completa permanecem apontando às publicações oficiais no LinkedIn.

O wordmark **ICON REALTY** permanece textual, conforme a escolha aprovada para evitar o uso de uma imagem de baixa qualidade.
